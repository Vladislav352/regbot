# Вывод косметической продукции (патчи, мази, гели, бальзамы, спреи из Китая, ТН ВЭД 3304990000) на рынок РФ/ЕАЭС по ТР ТС 009/2011 — состояние на сентябрь 2026

*Разведка для RAG-бота продуктолога (Анна).*

## 0. Ключевой контекст сентября 2026
С **24.12.2025** действует новая редакция ТР ТС 009/2011 (Изменения №3, Решение Совета ЕЭК № 114 от 29.11.2024; переходные периоды — Решение Коллегии ЕЭК № 24 от 04.03.2025). Часть новых требований (токсикология) — с **01.07.2026**, часть (14 новых запрещённых веществ) — с **28.10.2026**. Введено новое для отрасли понятие — **«ПКП, нанесённая на изделие-носитель»** (салфетки, патчи и т.п.), что напрямую касается бизнеса на патчах. Параллельно: с 01.10.2025 кремы/патчи (код 3304) под обязательной маркировкой «Честный знак», с 01.07.2026 — обязательный вывод из оборота через ККТ, с 01.09.2026 — обязательная ссылка на реестровую запись ФСА в карточке маркетплейса (546-ФЗ).
Источники: [ЕЭК — страница ТР ТС 009/2011](https://eec.eaeunion.org/comission/department/deptexreg/tr/bezopParfum.php), [Изменения с 24.12.2025 — certifikat.by](https://certifikat.by/articles/tr-ts-009-2011-klyuchevye-izmeneniya-s-24-12-2025-dlya-kosmeticheskoy-produktsii/), [Изменения №3 и переходные периоды — ПКАР](https://pcar.ru/news/2164), [rctest.ru](https://www.rctest.ru/news/sovet-eek-izmenil-tekhreglament-o-bezopasnosti-kosmetiki.html).

## 1. Форма подтверждения соответствия: декларация vs СГР

**Общее правило:** вся парфюмерно-косметическая продукция (ПКП) подтверждается **декларацией о соответствии** ТР ТС 009/2011; **СГР** — только для продукции из **приложения 12** к ТР.

**Перечень приложения 12** (ред. от 29.11.2024): 1) продукция для искусственного загара; 2) отбеливание/осветление кожи; 3) косметика для татуажа; 4) интимная косметика; 5) средства индивидуальной защиты кожи от производственных факторов; 6) детская косметика; 7) химическое окрашивание/осветление/мелирование волос, бровей, ресниц; 8) химическая завивка/распрямление; 9) продукция **с наноматериалами**; 10) средства для депиляции; 11) **пилинги**; 12) фторсодержащие средства гигиены полости рта (F >0,15%, жидкие >0,05%); 13) отбеливание зубов с H₂O₂ 0,1–6%; 14) **«семейная» косметика**, в т.ч. для детей до 14 лет (новая позиция Изменений №3).
Источники: [Приложение 12 — sudact.ru](https://sudact.ru/law/reshenie-komissii-tamozhennogo-soiuza-ot-23092011-n_14/tr-ts-0092011/prilozhenie-12/), [КонсультантПлюс](https://www.consultant.ru/document/cons_doc_LAW_120222/c98128882f1518901ae7c0e65a56649157644786/), [текст ТР ТС 009/2011 — docs.cntd.ru](http://docs.cntd.ru/document/902303206), [PDF ЕЭК](https://eec.eaeunion.org/upload/medialibrary/3ee/TR-TS-Parfum.pdf).

**Раскладка по ассортименту:**
- **Патчи для лица/глаз, мази-бальзамы, гели, спреи косметического назначения** — декларация о соответствии (если нет позиций из прил. 12).
- **СГР потребуется**, если: продукт заявлен как пилинг (в т.ч. кислотные патчи/пилинг-носочки!), отбеливающий/осветляющий кожу, для детей/«для всей семьи», для интимной гигиены, с наноматериалами (частый маркетинговый термин у китайских поставщиков — «nano» на упаковке автоматически тянет в СГР).
- **«Пилинг-носочки» для стоп** — классика СГР (пилинг).

**Может ли «детокс-патч для стоп» быть косметикой?** По определению ст. 3 ТР ТС 009 ПКП — вещество/смесь, наносимая **на внешний покров тела** с целью **очищения, изменения внешнего вида, придания запаха, защиты, сохранения в хорошем состоянии, ухода**. Кожа стоп — внешний покров, поэтому патч для стоп **может** быть косметикой, но только с косметическим назначением: допустимые формулировки — «уход за кожей стоп», «смягчение», «увлажнение», «дезодорирование», «снятие ощущения усталости ног», «освежающий». Формулировки «выводит токсины/шлаки из организма», «очищает организм», «нормализует сон/давление», «лечит» — **не косметические цели** и выводят продукт из-под ТР ТС 009 (см. п. 2). После Изменений №3 патчи прямо охвачены понятием «ПКП, нанесённая на изделие» — требования к таким носителям вступают в силу по мере включения методик испытаний в перечень стандартов ([ПКАР](https://pcar.ru/news/2164), [trts24 — патчи](https://trts24.ru/article/sertifikat-na-patchi-dlya-glaz), [gortestsibir](https://gortestsibir.ru/kosmetika-i-parfyumeriya/sertifikatsiya-patchej-dlya-glaz/)).

## 2. Что нельзя заявлять: граница косметика / медизделие / лекарство

- **Критерий — заявленное производителем назначение**, а не название или место продажи: как только на упаковке/в карточке появляется профилактика/лечение/диагностика заболеваний, воздействие на организм «изнутри» — это признаки медизделия (323-ФЗ, регистрация в Росздравнадзоре) или лекарства (61-ФЗ) ([centrattek](https://www.centrattek.ru/info/gde-posmotret-perechen-izdeliy-na-kotorye-neobhodimo-registracionnoe-udostoverenie/), [Brace — правовое регулирование ПКП](https://brace-lf.com/informaciya/farmatsevticheskoe-i-meditsinskoe-pravo/parfyumerno-kosmeticheskaya-produktsiya-pravovoe-regulirovanie)).
- **Опасные claims** для этой товарной группы: «лечит» (грибок, псориаз, боль в суставах), «обезболивает», «противовоспалительный», «снимает отёки» (как мед. эффект), «выводит токсины/шлаки», «детокс организма», «улучшает кровообращение/лимфоток», «нормализует обмен веществ», «от варикоза», «заживляет». Пластырь с заявленным лечебным действием — медизделие с РУ Росздравнадзора; продажа без РУ — ст. 6.33 КоАП/уголовные риски, немедленная блокировка на маркетплейсах.
- «Патчи косметические для ухода за кожей» РУ не требуют — подтверждается практикой классификации Росздравнадзора ([реестр МИ](https://roszdravnadzor.gov.ru/services/mi_reesetr)).
- **Реклама**: приписывание косметике лечебных свойств = недостоверная реклама (ст. 5 38-ФЗ «О рекламе»); штрафы для юрлиц 200–500 тыс. руб. за эпизод; практика ФАС — запрет рекламы детского крема «от дерматита», крем-бальзам «Стопдиатез» ([Право.ру](https://pravo.ru/news/view/21575/), [e-kontur](https://e-kontur.ru/enquiry/1358/advert_law), [belberry](https://belberry.net/blog/kak-reklamirovat-bad-bez-shtrafov-zapreshchennye-formulirovki-i-primery/)).
- **Практический вывод для «детокс»-брендов**: слово «detox/детокс» терпят, пока оно читается как образное «очищение кожи». «Детокс-патч для стоп, выводящий токсины из организма через точки стопы» — прямой риск: (а) переквалификация в медизделие/«псевдомедицинский товар», (б) ст. 14.7/14.8 КоАП (обман потребителя), (в) недостоверная реклама, (г) заявленные свойства по ТР ТС 009 должны быть **доказательно подтверждены** — «вывод токсинов» подтвердить нельзя. Рекомендованная замена: «уход за кожей стоп», «релакс-эффект», «освежает и дезодорирует», «способствует комфорту ног».

## 3. Процедура декларирования

- **Заявитель — только резидент ЕАЭС**: изготовитель ЕАЭС, либо импортёр/уполномоченное изготовителем лицо по договору уполномоченного представителя с китайским заводом ([gortest](https://gortest.com/po-produkcii/kosmetika/sertifikaciya-kosmetiki-iz-kitaya/), [gortestsibir](https://gortestsibir.ru/sertifitsirovanie/sertifikatsiya-v-kitae/deklaratsiya-sootvetstviya-tamozhennogo-soyuza-na-kitajskie-tovary/)).
- **Схемы**: **3д** — серийный выпуск; **4д** — партия; **6д** — серия при наличии у производителя сертифицированной СМК/GMP (ISO 22716). Срок действия: 3д/4д — до 5 лет (4д — на срок годности партии), 6д — до 7 лет; протоколы для 3д/6д — не старше 1 года на дату регистрации, для 4д — до 2 лет ([redico](https://redico.ru/009-tr-ts-sertifikacziya-kosmetiki/), [gkstandart](https://gkstandart.com/deklaratsiya-sootvetstviya-na-parfyumeriyu-poshagovaya-instruktsiya-po-tr-ts-009-2011/), [tkcert](https://tkcert.su/tehniceskii-reglament-tamozennogo-soyza/tr-ts-009-2011.html)).
- **Испытания** в аккредитованной лаборатории (реестр — pub.fsa.gov.ru/ral): микробиология, физико-химия (pH, тяжёлые металлы — Hg, Pb, As), токсикология (in vitro; с 01.07.2026 — обновлённые требования), при заявленных особых свойствах — клинические/потребительские подтверждения ([sertcity](https://sertcity.ru/documenti/tr-ts-009-2011), [rossertcentr](https://rossertcentr.ru/stati/kak-oformit-deklaratsiyu-o-sootvetstvii-na-kosmetiku-i-parfyumeriyu-v-2026)).
- **Документы от китайского производителя**: полный состав с концентрациями (INCI), спецификация/паспорт качества, контракт + договор уполномоченного лица, инвойс на образцы, макет маркировки; желательно ISO 22716/GMP для схемы 6д ([serconsrus](https://www.serconsrus.ru/services/tr-ts/009-2011/)).
- **Регистрация** — заявителем самостоятельно через ФГИС Росаккредитации (ЭЦП), протоколы обязаны быть в реестре. Ориентиры: **от ~15–25 тыс. руб. за наименование** с протоколом, срок **5–12 рабочих дней** от готовности образцов (реально с логистикой образцов из Китая — 3–6 недель) ([rospromtest](https://www.rospromtest.ru/sertifikati/deklaratsiya-sootvetstviya-na-kosmetiku/), [eacportal](https://eacportal.com/deklaraciya-sootvetstviya-na-kosmetiku/)). ⚠️ С 01.01.2026 ФГИС применяет автоматический (нейросетевой) анализ деклараций — «быстрые» декларации без реальных испытаний почти гарантированно ловятся ([sertiftrade](https://sertiftrade.ru/blog/sertifikacziya-kosmetiki-ruchnoj-raboty-2026-gajd-ot-sertiftrade/)).

## 4. Процедура СГР

Госрегистрация ведётся **Роспотребнадзором** (в РФ) с внесением в Единый реестр СГР ЕАЭС; действует на всей территории Союза. СГР, выданные до 24.12.2025, действуют **60 месяцев с 24.12.2025** (переходное положение Изменений №3). Отличия от декларации: регистрирует госорган (а не сам заявитель), расширенный объём испытаний и экспертиза документации, образцы с русскоязычной маркировкой (3–5 шт. на наименование), сроки **от 30–60 рабочих дней (реально 1–3 месяца)**, стоимость под ключ — **от ~65 тыс. руб. за наименование** + госпошлина (5 000 руб.). Источники: [sertiki](https://sertiki.ru/sgr-na-kosmetiku), [serter — инструкция 2026](https://serter.ru/blog/kak-poluchit-sgr-instruktsiya), [multicert](https://multicert.ru/sgr-na-kosmetiku-i-himiyu), [serconsrus](https://www.serconsrus.ru/services/sertifikaciya/rospotrebnadzor-svidetelstvo-sgr/), [ПКАР](https://pcar.ru/news/2164).

## 5. Маркировка

**А. Потребительская маркировка по ТР ТС 009 (ст. 5, п. 9.2):** наименование и назначение; изготовитель (наименование, юр. адрес, страна); страна происхождения; **уполномоченное лицо/импортёр в ЕАЭС** (приём претензий); номинальный объём/масса; срок годности; условия хранения (если особые); особые предупреждения (в т.ч. из приложений 2–5 по ингредиентам); номер партии; **список ингредиентов по убыванию — допускается INCI латиницей**; сведения об эффективности (если заявлена — с подтверждением). При нехватке места — вкладыш + знак «рука на книге». Знак EAC обязателен. Изменения №3 уточнили требования с 24.12.2025. Источники: [sertiftrade — этикетка](https://sertiftrade.ru/blog/etiketka-kosmetiki-po-tr-ts-009-6-pravil-dlya-importera/), [moseac](https://moseac.ru/markirovka-tovarov-category/markirovka-po-tr-ts-009-2011), [ogost](https://ogost.ru/trts/trts009/).

**Б. «Честный знак»** (ПП РФ от 30.11.2024 №1681; встречающийся в некоторых источниках реквизит «№1641 от 27.11.2024» — ошибка, такого ПП не существует): этапы нанесения кодов: 01.05.2025 — мыло/моющие (3401, 3402…); 01.07.2025 — средства для волос, бритья, дезодоранты (3305, 3307); **01.10.2025 — код ТН ВЭД 3304 (кремы, средства ухода за кожей — т.е. патчи, мази-бальзамы косметические, гели под 3304990000) и 3306**; 01.12.2025 — бритвы (ПП № 808 от 31.05.2025). **С 01.07.2026 — обязательный вывод из оборота через ККТ с передачей в ЧЗ**. Объёмно-сортовой учёт — до 01.07.2028, затем поэкземплярный. Остатки, выпущенные/ввезённые до дат этапов, продаются без кодов до конца срока годности (для отдельных групп — маркировка остатков до 30.11.2026). ПП № 656 от 30.05.2026 расширило перечень (товары личной гигиены — салфетки, ватные изделия и пр.) с 01.10.2026. **Вывод: ввозимые патчи/кремы под 3304990000 уже сейчас требуют кода Data Matrix до выпуска в оборот; импортёр маркирует до/в ходе таможенных процедур.** Источники: [markirovka.ru](https://markirovka.ru/community/markirovka-kosmetiki-i-bytovoy-khimii/markirovka-kosmetiki-i-bytovoy-khimii-sroki-etapy-i-chto-nuzhno-znat-uchastnikam-oborota-v-2026-godu), [МойСклад](https://www.moysklad.ru/poleznoe/markirovka-tovarov/markirovka-kosmetiki-i-bytovoy-himii/), [ПП (ред. 30.05.2026) — КонсультантПлюс](https://www.consultant.ru/document/cons_doc_LAW_491963/), [ПП № 656 — Альта-Софт](https://www.alta.ru/tamdoc/26ps0656/), [Контур](https://kontur.ru/articles/54895-rabotat_s_markirovkoj_kosmetiki_i_bytovoj_ximii).

## 6. Проверка деклараций и риски аннулирования

- **Реестр**: [pub.fsa.gov.ru/rds/declaration](https://pub.fsa.gov.ru/rds/declaration) — поиск по номеру (ЕАЭС N RU Д-CN.РА01…), ИНН заявителя, наименованию; проверять статус «действует», соответствие наименования/кодов реальному товару, лабораторию и протоколы ([rctest — обзор реестров](https://www.rctest.ru/articles/reestry-eaes-ts-akkreditovannykh-lits-sertifikatov-i-deklaratsiy-sgr-notifikatsiy-res-i-vchu.html)).
- **Частые причины прекращения**: протоколы «нарисованы» (лаборатория их не выдавала / лишена аккредитации), испытания без реального образца, несоответствие состава, ошибки в наименовании/адресах, «пакетные» отмены документов конкретного органа. С 2025–2026 ужесточение: Росаккредитация вправе прекращать в РФ действие сертификатов/деклараций, оформленных с нарушениями **в других странах ЕАЭС**, и уже массово прекращала документы органов Киргизии и Армении; с 01.01.2026 работает автоматический анализатор деклараций во ФГИС ([Альта-Софт 13.11.2025](https://www.alta.ru/laws_news/123231/), [Альта-Софт 17.02.2026](https://www.alta.ru/external_news/125721/), [Ведомости](https://www.vedomosti.ru/press_releases/2026/02/18/rosakkreditatsiya-prekratila-deistvie-na-territorii-rossii-vseh-dokumentov-treh-organov-po-sertifikatsii-stran-eaes), [avangard-direct](https://avangard-direct.ru/news/rasshirili-usloviya-blokirovki-i-annulirovaniya-sertifikatov-sootvetstviya-fev-2026/), [sert-plus](https://sert-plus.ru/news/prichini_annulirovaniya_sertifikata_i_deklaratsii_sootvetstviya)).
- **Последствия для селлера**: с момента прекращения декларации товар вне закона (ст. 14.43–14.45 КоАП, штрафы до 300 тыс.–1 млн руб. с конфискацией), маркетплейс скрывает карточки и может удерживать выплаты. Не покупать «декларацию за 3 дня без образцов», проверять лабораторию в реестре, хранить свои протоколы.

## 7. Правила Ozon / Wildberries

- Обе площадки работают по модели «документы по запросу» (72 часа — 3 дня), но тренд 2025–2026 — упреждающая загрузка: с сентября 2025 карточки блокируются за отсутствие разрешительных документов; **в апреле 2026 Ozon потребовал загрузить документы по всем товарам до 01.10.2026** под угрозой скрытия карточек ([scloud](https://scloud.ru/blog/wildberries_i_ozon_ne_budut_prodavat_tovary_bez_sertifikatov_kak_selleru_spasti_postavki_v_2026/), [uniseller](https://uniseller.io/blog/dokumenty-na-tovary-ozon-wildberries-2026/)).
- Для косметики требуются: декларация ТР ТС 009 или СГР (для прил. 12), для «детокс-пластырей» с мед. позиционированием площадка запросит РУ Росздравнадзора; также согласие правообладателя/разрешение на бренд ([normasert](https://normasert.ru/production/kosmetika-dlya-marketplejsov-wildberries-ozon-kakie-dokumenty-nuzhny-i-kak-oformit/), [global-standart](https://global-standart.ru/info/articles/stati/sertifikatsiya-tovarov-dlya-marketpleysov-wildberries-ozon-yandeks-market-kakie-dokumenty-nuzhny-kak/)).
- **С 01.09.2026 (ФЗ № 546-ФЗ от 28.12.2024)**: в карточке товара обязательна **активная ссылка на реестровую запись** pub.fsa.gov.ru / единого реестра ЕАЭС (не скан!); отсутствие ссылки = отсутствие документа; площадки внедряют автоматическую сверку карточек с реестром ([oborot.ru](https://oborot.ru/news/novyj-zakon-obyazal-marketplejsy-i-sellerov-razmeshhat-v-kartochke-tovara-ssylku-na-reestr-sertifikatov-rosakkreditacii-no-mozhno-ne-speshit-i231527.html), [law.ru](https://www.law.ru/news/40895-s-1-sentyabrya-2026-goda-marketpleysy-budut-razmeshchat-ssylki-na-sertifikaty-sootvetstviya), [serconsrus](https://www.serconsrus.ru/blog/avtomaticheskaya-proverka-sertifikatov-i-deklaraczij-na-marketplejsah-kak-rabotaet-novyj-servis-i-chto-proverit-prodavczam/)).
- Типовые причины блокировок косметики: прекращённая декларация, несовпадение наименования/бренда в документе и карточке, лечебные claims в описании (модерация + жалобы конкурентов), отсутствие кода ЧЗ.
